# STLCPipeline

GitHub Copilot STLC workflow. Custom agents and related Copilot files are in
[`.github/`](.github/); the Java/Python workflow and artifacts are in
[`stlc-pipeline/`](stlc-pipeline/).

See [`stlc-pipeline/README.md`](stlc-pipeline/README.md) for the workflow,
approval gates, integrations, and validation commands.
