🪝 Hook Lifecycle (Pre-Check & Post-Check)

🔴 Pre-Stage-Validation Hook
Runs BEFORE each stage:
  • Validates artifact contracts
  • Checks Java validation requirements
  • Validates input prerequisites
  • Verifies MCP readiness
📁 .claude/hooks/pre_stage_validation.py
🟢 Approval-Gate-Guard Hook
Runs AFTER each stage:
  • Enforces HITL approvals
  • Validates stage outputs
  • Checks quality gates
  • Allows/blocks progression
📁 .claude/hooks/approval_gate_guard.py
