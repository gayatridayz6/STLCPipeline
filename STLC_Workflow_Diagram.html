8-Stage STLC Workflow (Stage 4 is split into 4a and 4b)

1. Take Input

Agent: triage-agent
Input: Jira ticket
Process: Parse requirement
Output: Routing decision
PRE-CHECK

2. Test Planning

Agent: qa-strategist
Input: Approved Stage 1 analysis
Output: Risk-based test plan
HUMAN REVIEW

3. Test Design & BDD

Agent: qa-sentinel
Input: Approved Stage 2 plan
Output: BDD test design
HUMAN REVIEW

4a. Engineering

Agent: engineer-agent
Input: Approved Stage 3 design
Output: Engineering summary

4b. Test Execution

Agent: qa-runner-agent
Gate: Explicit execution approval
Output: Actual execution evidence

5. Security & Compliance

Agent: security-gate-agent
Evidence: Actual approved scan results only
Output: Security report

6. PR Review

Agent: github-mcp-agent
Output: Review and merge-readiness summary
Mutation: Requires explicit approval

7. Human Decision

Agent: hitl-gate-agent
Decision: Explicit go/no-go
Output: Audit trail
APPROVAL GATE

8. Closure & Reporting

Agent: reporting-closure-agent
Artifact: test_closure_metrics.md
Jira: Sync-ready report only unless approved
FINAL

📊 Data Flow Summary:
INPUT: Jira issue key or pasted requirements
CONFIG: Copilot agent files and workflow manifest; MCP references are not active connections
ENTRY POINT: Local-agent prompt `.github/prompts/stlc.prompt.md`; invoke the orchestrator agent directly in Agent Host
ARTIFACTS: Stage outputs are stored under `stlc-pipeline/artifacts/`
GATES: Human approval required where configured; unavailable tools or integrations block dependent stages
