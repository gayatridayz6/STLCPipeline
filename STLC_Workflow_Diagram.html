8-Stage Workflow (branches/loop shown) - MCP Integration Points

1. Take Input

Agent: triage-agent
Input: Jira ticket
Process: Parse requirement
Output: Routing decision
PRE-CHECK

2. Fetch Build Data

Agent: qa-strategist
MCP Call: get_build_info
Fetches: Build metadata, test report
MCP TRIGGER

3. Analyze & Summarize

Agent: qa-sentinel
Analyzes: Pass/Failed/Skipped metrics
Output: Test planning artifact
POST-CHECK

4A. Human Review [Human]

Gate: HITL approval required
Reviews: Test plan adequacy
Decision: Approve/Reject/Modify
APPROVAL GATE

5. RCA + QE Radar Tag

Analyzes: Root cause analysis
Tags: QE Radar categories
Output: Categorized issues

6. Human Approval [Human]

Gate: Final approval required
Category: approve/fix/confidence
APPROVAL GATE

7. Fix, Push & Re-run

Triggers: Pre-push HOOK + MCP trigger
MCP: trigger_build
Monitors: get_build_status piling

8. Publish Summary

Output: approve → Confidence
Artifact: test_closure_metrics.md
FINAL

9. Log Defect (if any)

Creates: Standard template → Confluence
Links: Jira ticket → defect log
CLOSURE
