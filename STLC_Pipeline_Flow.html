8-Stage Workflow (branches/loop shown) - MCP Integration Points

1. Take Input

Agent: triage-agent
Skill: 01-requirements-analysis
Input: Jira ticket + Build number
Process: Extract requirements & acceptance criteria
Output: requirement_analysis.md
PRE-CHECK

2. Fetch Build Data

Agent: qa-strategist-agent
Skill: 02-test-planning
MCP: get_build_info | fetch_test_report
Fetches: Build metadata & test reports
Output: test_planning.md
MCP ENABLED

3. Analyze & Summarize

Agent: qa-sentinel-agent
Skill: 03-test-design
Analyzes: Pass / Failed / Skipped metrics
Process: Create test scenarios & BDD
Output: test_design.md
PRE-CHECK

4. Human Review [Human]

Gate: HITL Approval
Question: Which failures to analyze?
Decision: Approve / Request Changes
APPROVAL GATE

5. RCA + QE Radar Tag

Agent: security-gate-agent
Skill: 05-security-gate
Process: Root Cause Analysis & Tagging
Categorize: QE Radar classification
Output: security_compliance_report.md

6. Human Approval [Human]

Gate: HITL Approval
Approves: Category / approve fix?
Confidence: approve → Confidence
APPROVAL GATE

7. Fix, Push & Re-run

Agent: engineer-agent
Skill: 04a-engineering
Triggers: Pre-push HOOK + MCP trigger
MCP: trigger_build
Monitors: get_build_status polling
MCP TRIGGER

8. Publish Summary

Agent: reporting-closure-agent
Skill: 08-closure-sync
Output: approve → Confidence
Artifact: test_closure_metrics.md
FINAL
