8-Stage STLC Workflow

1. Take Input

Agent: triage-agent
Skill: jira-parser
Input: Jira issue or pasted requirements
Process: Extract requirements & acceptance criteria
Output: requirement_analysis.md
PRE-CHECK

2. Test Planning

Agent: planning-agent
Skill: test-planning-strategist
Input: Approved Stage 1 analysis
Defines: Risk, scope, environment, exit criteria
Output: test_planning.md
HUMAN REVIEW

3. Test Design & BDD

Agent: test-design-agent
Skill: bdd-generator
Process: Create BDD scenarios from approved planning
Output: test_design.md
PRE-CHECK

4a. Engineering

Agent: engineer-agent
Input: Approved Stage 3 design
Output: engineering_summary.md

4b. Test Execution

Agent: execution-agent
Gate: Explicit execution approval and verified target
Output: test_execution_report.md

5. Security & Compliance

Agent: security-gate-agent
Skill: security-compliance-review
Evidence: Actual approved scan results only
Output: security_compliance_report.md

6. PR Review

Agent: github-mcp-agent
Output: Review summary and merge-readiness notes
Gate: PR mutations require approval

7. Human Decision

Agent: hitl-gate-agent
Decision: Explicit go/no-go from human
Output: hitl_audit_trail.md
APPROVAL GATE

8. Publish Summary

Agent: reporting-closure-agent
Skills: evidence and audit writers
Output: Closure metrics; Jira sync-ready only
Artifact: test_closure_metrics.md
FINAL
Legend:
Stages 1-3 (Requirements, planning, test design)
Stages 4-5 (Engineering, execution, security)
Stages 6-7 (PR review and human decision)
