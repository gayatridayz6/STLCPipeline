Configured workflow

  1. Stage 1 — Requirements
    Analyze input, inspect existing test coverage, and choose one route.
  2. Reuse route
    Skip Stages 2, 3, and 4a; run Stage 4b in execution-summary-only mode, then stop.
  3. Stage 2 — Planning
    Produce a risk-based test plan; honor configured approval.
  4. Stage 3 — Test design
    Create approved test design and BDD assets.
  5. Stage 4a — Engineering
    Produce the engineering summary; runs before Stage 4b.
  6. Stage 4b — Execution
    Requires an approved, verified target; report real evidence or accurately mark review-only.
  7. Stage 5 — Security
    Use actual approved scan evidence only.
  8. Stage 6 — PR review
    Prepare review material; PR mutations require approval and an available integration.
  9. Stage 7 — Human decision
    Record the human's explicit go/no-go decision.
  10. Stage 8 — Closure
    Prepare closure metrics; Jira sync requires approval and an available integration.

MCP preflight checks only integrations required by the selected route. Stop on missing approvals, tools, inputs, or evidence; do not claim blocked work completed.
